# Frontend

The frontend in `frontend/` is a React application built with Vite, using Chakra UI, TanStack Router and Query, and CesiumJS for the map.

## Dev server

Run it on your machine, against the backend of the [local stack](./):

```bash
cd frontend
nvm use
npm ci
npm run dev
```

Open `http://localhost:5173`. Changes reload in the browser on save.

`nvm use` picks the Node version from `.nvmrc`. The first `npm run dev` also copies the Cesium static files to `public/cesium/`.

## Configuration

The dev server reads `frontend/.env`. `VITE_API_URL` points to the backend, `http://localhost` by default.

The Docker image is built once for every environment: the values are placeholders (`DTT_API_URL` and so on, see `.env.production`), replaced when the container starts with the `DTT_*` variables of the root `.env`.

## API types

`src/api/schema.gen.ts` holds the TypeScript types of the API, generated from the OpenAPI schema of the running backend. After changing a model or a route in the backend, regenerate it with the local stack up:

```bash
npm run generate-types
```

Commit the result, don't edit it by hand.

## Pages

Routes are files in `src/routes/`, picked up by TanStack Router. `src/routeTree.gen.ts` is generated by the dev server and the build: commit it, don't edit it.

## Lint, test and build

```bash
npm run lint
npm test
npm run build
```

`lint` runs [Biome](https://biomejs.dev/) and fixes what it can, so it may change files. `test` runs the unit tests with [Vitest](https://vitest.dev/). `build` type checks and writes the production bundle to `dist/`. CI runs `npx biome ci .`, `npx tsc --noEmit` and `npm test`.
