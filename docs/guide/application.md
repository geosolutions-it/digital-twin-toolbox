# The application

The application has three pages, in the sidebar on the left.

## Assets

Browses the bucket. Upload files here, then start a job on a file with **Process**, or on a whole folder with **Batch**.

See [Jobs and batches](./pipelines).

## Pipelines

Lists jobs and batches with their status. From here you follow their logs, re-run, cancel, change options, download and delete them.

See [Jobs and batches](./pipelines#follow-the-progress).

## Map

Shows every successful result on a 3D globe. The panel turns the layers on and off and selects the terrain.

See [Terrain](./workflows/terrain#output) for using a terrain as the ground.
